# 도고 1박 2일 · 5인 일정표

정적 페이지 하나 + JSON 세 개. GitHub Pages에 그대로 올라갑니다.

```
index.html
data/trip.json       사람 · 장소 좌표 · 일정
data/packing.json    준비물
data/shopping.json   쇼핑리스트
```

## 올리기

1. 저장소를 만들고 위 파일들을 루트에 그대로 넣습니다.
2. Settings → Pages → Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 지정합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

`data/` 폴더 이름과 위치를 바꾸면 `index.html` 맨 위의 `SOURCES` 도 같이 바꿔야 합니다.

## JSON 고치면 반영됩니다

깃허브 웹에서 `data/shopping.json` 을 열고 연필 아이콘으로 고쳐서 커밋하면, 배포가 끝난 뒤(보통 30초~1분) 페이지를 새로고침할 때 반영됩니다. 페이지는 매번 캐시를 우회해서 파일을 다시 읽습니다.

바로 안 보이면 배포가 아직 안 끝난 겁니다. Actions 탭에서 초록 체크를 확인하거나, 목록 위의 **파일에서 다시 불러오기** 버튼을 누르세요.

### 준비물 · 쇼핑리스트 형식

```json
{
  "groups": [
    {
      "name": "분류 이름",
      "items": [
        "이름만 있는 항목",
        { "name": "삼겹살", "qty": "2kg" },
        { "name": "수영복", "note": "설명은 작은 글씨로 붙습니다" }
      ]
    }
  ]
}
```

`qty` 는 이름 옆에 초록색으로, `note` 는 아래 줄에 회색으로 붙습니다. 둘 다 없어도 됩니다.

### 일정 형식 (`data/trip.json`)

`places` 에 장소를 등록하고, `schedule` 에서 키로 참조합니다.

| 필드 | 설명 |
|---|---|
| `day` | 1 또는 2 |
| `start` `end` | `"09:00"` 형식. `end`는 `null` 가능 |
| `kind` | `"move"` 이동 / `"stay"` 머무름 |
| `who` | `"all"` 또는 `["suhyuk","yongmin"]` |
| `from` `to` | `move`일 때 `places` 키 |
| `place` | `stay`일 때 `places` 키 |
| `mode` `mins` `km` | 이동 수단 · 소요분 · 거리 |
| `fixed` | `true`면 못 움직이는 시각 (붉은 사각 마커) |
| `back` | 역산 근거. `"용민 도착 10:00 기준"` 처럼 |
| `note` | 상세 패널에 나오는 메모 |

좌표는 대략값입니다. 정확히 맞추려면 구글 지도에서 장소를 우클릭해 나오는 위·경도를 `lat` `lng` 에 넣으세요.

## 체크 상태와 앱에서 한 수정

- **체크 상태**는 브라우저(localStorage)에 기기별로 저장됩니다. 5명이 각자 체크하면 서로 안 보입니다. 같이 보려면 카톡이나 별도 도구를 쓰세요.
- 앱에서 항목을 추가·삭제하면 그 기기에만 남습니다. 모두에게 반영하려면 **JSON 내보내기** 로 받은 파일을 `data/` 안에 같은 이름으로 덮어쓰고 커밋하세요.
- 저장소의 JSON이 바뀌면 그 기기의 임시 수정은 자동으로 버려지고 파일 내용이 이깁니다. 즉 파일이 항상 원본입니다.

## 로컬에서 확인할 때

`index.html` 을 더블클릭해서 열면 브라우저가 `file://` 에서 JSON 읽기를 막아, 안에 넣어둔 예비본으로 뜹니다. JSON 수정을 확인하려면 간단한 서버를 띄우세요.

```
python3 -m http.server 8000
```

그 다음 `http://localhost:8000` 으로 접속합니다.
